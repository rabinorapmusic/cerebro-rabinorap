# 🧠 CEREBRO RABINO PRO v1.5

**El Estudio Musical IA de Rabino Rap**
*Genera canciones completas con IA - 100% Gratis con Suno.com*

## 🔥 DESCRIPCIÓN

CEREBRO RABINO PRO es un asistente web para crear música cristiana con IA. 
Te ayuda a generar prompts profesionales para Suno AI, organizar letras, portadas y exportar tu música.

Hecho para productores que quieren sacar música rápido sin pagar suscripciones caras.

## ✨ FUNCIONES ACTUALES

- **🎵 SUNO MASTER**: Genera prompts completos para Suno con BPM, género, instrumentos y estructura
- **✍️ GENERADOR DE LETRAS**: Espacio para escribir y guardar letras
- **🎨 GENERADOR DE PORTADAS**: Próximamente con IA local
- **📦 EXPORTAR**: Sube y guarda tus MP3/WAV de Suno
- **🎚️ MIX**: Guarda presets de tus beats favoritos

## 🛠️ REQUISITOS

- Python 3.10 o superior
- Conexión a internet
- Cuenta gratis en [Suno.com](https://suno.com)
